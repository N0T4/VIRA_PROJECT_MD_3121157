# T070 — API для української, англійської та російської

Перевірено 2026-11-05 за запитом власника: знайти придатні API без уже наявних у нього ключів. Це доповнення до [дослідження відеоджерел](16_PROVIDER_CAPABILITIES.md), не мовчазна заміна джерел. Жоден кандидат ще не вибрано як реалізований provider VIRA.

## Рекомендація

Першим кандидатом для українського каталогу й серій є **Mikai**. Для англійських метаданих — **Kitsu**, для російських — **Shikimori**. Усі три повернули HTTP 200 на мінімальні анонімні запити. Це запропонована комбінація; повноту перекладів для всього каталогу та права artwork потрібно перевіряти окремо.

Мова назв/описів, мова озвучення та мова субтитрів — окремі властивості. Мовні поля каталогу не підтверджують відповідних аудіодоріжок. Повного перевіреного внутрішнього перегляду UK/EN/RU ця перевірка не отримала.

Власник уточнив: **мови потрібні для обох — каталогу та перегляду (озвучення/субтитри)**. Тому запропонована комбінація metadata API покриває лише частину вимоги. Жодна з проб не підтверджує відео всіма трьома мовами на Quest.

## Кандидати

| API | Доступ і метадані | Серії / відео | Статус |
|---|---|---|---|
| [Mikai](https://api.mikai.me/public/docs) | Ключ необов’язковий. Українські описи, UA/EN/original назви, зовнішні ID | Документовані voice/sub релізи за командами; серії містять provider embedUrl | Каталог і API серій — HTTP 200; embed/Quest не запускали |
| [Kitsu](https://hummingbird-me.github.io/api-docs/) | Більшість публічних GET без авторизації; англійські назви, synopsis, episodeCount | Episode resources документовані; відеопотік цим не надається | Мінімальні деталі — HTTP 200; окремий список серій не тестували |
| [Shikimori](https://shikimori.io/api/doc) | Публічні деталі повернулися без ключа; російська назва/опис, англійські назви, MAL ID | Загальний лічильник; у перевіреному videos були лише pv, не повні серії | Деталі — HTTP 200; native playback не підтверджено |
| [AniHub](https://dev.anihub.in.ua/api-docs/anime) | Без ключа; український каталог, англійські назви, зовнішні ID | У переглянутих схемах не підтверджено окремий playable episode inventory | Каталог — HTTP 200; у вибірці українська назва була порожня |
| [YummyAnime](https://api.yani.tv/swagger) | Обов’язкова власна реєстрація application і X-Application token; документовано Lang ru/en/uk | Схема videos має iframe_url, dubbing, player і номер серії; не native MP4/HLS | Документація прочитана; API без ключа не тестували |
| [Jikan](https://github.com/jikan-me/jikan-rest/blob/master/storage/api-docs/api-docs.json) | Без ключа, read-only метадані MAL; неофіційний сервіс | Episode metadata; streaming — посилання на сервіси, не відеопотік | Дві спроби отримати один тайтл завершилися timeout; live доступність не підтверджена |

## Умови та технічні межі

**Mikai.** Розділ «Використання та атрибуція» дозволяє дані у власних застосунках із посиланням на джерело, збереженням авторства команд/постерів та без масового дзеркалювання відео. Плеєрні посилання належать провайдерам; це не загальний дозвіл ретрансляції. Licensed-виключення можуть повертатися без джерел. [Документація](https://api.mikai.me/public/docs).

Для `mal:1` публічний API серій повернув п’ять релізів: два voice по 26 записів, sub на 1, 26 і 1 запис. Це перелік даних API, не п’ять переглянутих відео. Відповіді й embed-адреси повністю не зберігали; зафіксовано лише кількості, SHA-256 і типи..

**Kitsu / Shikimori.** Метадані доступні в пробах, але повні умови використання даних/постерів у цьому короткому відборі не перевірені. Ліцензія документації чи коду не є автоматичним дозволом на весь контент. Shikimori вимагає описовий User-Agent, документує ліміти та радить GraphQL замість застарілого v1/v2; фактична проба була REST v1, а не тест майбутнього GraphQL-адаптера.

**YummyAnime.** Документація прямо обмежує використання personal use; комерційне погоджується окремо. [Реєстрація власного application](https://yummyani.me/dev/applications) не виконувалася. Lang визначає мову відповіді, а не гарантує три озвучки. Фактичне наповнення перекладів без application token не перевіряли. Public swagger описує iframe, не готовий native playback-контракт.

**AniList.** Не обрано стартовою базою: поточні [умови](https://docs.anilist.co/guide/terms-of-use) обмежують конкуруючі/non-complementary list/tracker-сервіси, включно з media data. Наявність Library у VIRA потребує уточнення застосовності цього правила. Публічні дані без OAuth не скасовують умов.

**Jikan.** Timeout у web tool й у звичайному HTTP-клієнті не доводить глобальний outage; статус HTTP/тіло не отримано. Це резервний кандидат після повторної перевірки. Ліцензія MIT коду не поширюється автоматично на дані MAL.

## Перегляд UK/EN/RU після уточнення власника

| Мова | Каталог | Озвучення / субтитри й відтворення |
|---|---|---|
| Українська | Mikai, HTTP 200 | API повернув voice/sub релізи; самі iframe, звук, субтитри й Quest не тестували |
| Англійська | Kitsu, HTTP 200 | Метадані Kitsu не є відеоджерелом. Документовані embed-кандидати потребують конкретного дозволеного тайтлу, перевірки доріжок і Quest |
| Російська | Shikimori, HTTP 200 | Shikimori не підтвердив повні серії. Для YummyAnime потрібен власний application token; фактичні мови озвучення/субтитрів ще не звірено |

**YummyAnime / Kodik.** Перегляд схеми YummyAnime не встановив ISO-переліку мов аудіо/субтитрів. Анонімний GET [сторінки applications](https://yummyani.me/dev/applications) дав HTTP 401; вхід/реєстрацію не виконували. Для Kodik поточний публічний контракт не отримано: `https://kodik.biz/` дав web 502/DNS error, `https://kodik-api.com/` — HTTP 401. Ці помилки не доводять відсутності API, але не дають перевіреного доступу VIRA. Чужі ключі й extractor-рецепти не використовували.

**YouTube IFrame API.** [Офіційний інтерфейс](https://developers.google.com/youtube/iframe_api_reference) документує play/pause/seek та події для конкретного відео; standalone embed не потребує YouTube Data API key. Параметри [субтитрів](https://developers.google.com/youtube/player_parameters) вибирають лише наявні доріжки. Каталог/пошук Data API — окремий доступ. Потрібні дозволений ролик, територія й дотримання [вимог плеєра](https://developers.google.com/youtube/terms/required-minimum-functionality), включно з client identity для WebView. Це технічний шлях для погоджених відео, не знайдений універсальний каталог аніме й не MP4 для поточного MediaPlayer. Конкретну повну серію не вибрано; VIRA WebView/embed та Quest — NOT_IMPLEMENTED / NOT_RUN.

**Інші публічні embed-кандидати, лише документація.** [Yenime](https://api.yenime.net/) описує SUB/DUB, iframe та події стану; [Aniweeb](https://api.aniweeb.net/docs) — безключові JSON-списки серій, sub/dub availability та iframe. В оглянутих сторінках не підтверджені конкретні UK/EN/RU доріжки, права на каталог і дозволи кожного джерела. Їх episode/embed/stream endpoints не викликали; провайдерами VIRA не обирали. Вони не закривають критерій тримовного перегляду лише фактом існування сторінки документації.

Наступна перевірка перегляду має для конкретного дозволеного епізоду зафіксувати мову аудіо, мову субтитрів, доступність у країні, режим embed/native, pause/seek і відображення на Quest. Лише після цього capability можна позначати перевіреною. Подія ended сама по собі не підтверджує повний перегляд для T052.

## Вимоги до реалізації адаптера

- Поєднувати джерела через підтверджені зовнішні ID/таблицю відповідностей, зберігати provider provenance для кожного мовного поля. У Kitsu окремий ID-простір; відповідність MAL не виводити з однакового числа або назви.
- Не видавати транслітерацію за англійський переклад; відсутні поля показувати чесно. Запит локалізації не гарантує повноти каталогу.
- Зберегти demo IDs та деталі старих записів Library. Не передавати реальні тайтли в `demoEpisodesFor`; епізоди мають походити з реального provider або показувати відсутність даних. [Технічна база](05_TECHNICAL_BASELINE.md).
- У Mikai релізи й джерела не дорівнюють новим канонічним епізодам. Номери можуть бути дробовими; не відкидати частину числа й не зараховувати одну серію повторно за різне озвучення. Адаптація до T052 потребує явної episode identity.
- Розділити мову UI, metadata locale, audio language та subtitle language. Перед Play перевіряти реальну наявність, територію, права й режим embed/native. Не вважати iframe готовим входом поточного raw-only MediaPlayer.

## Що реально виконано

Публічні документи та мінімальні GET без ключів/акаунтів.. П’ять різних запитів до метаданих/серій Mikai, AniHub, Kitsu та Shikimori дали HTTP 200; повтор Shikimori для фіксації hash — той самий ресурс. У Jikan отримано лише timeout. Не створювали акаунтів чи application keys, не викликали чужими ключами, не завантажували iframe, manifest або медіа.

**Build verification: NOT_RUN. Quest verification: NOT_RUN.** Android-код, APK, upstream lock, Room, сцена й моделі не змінені. Нові джерела лише запропоновано; T071 не реалізовано.
