# Етапи та критерії завершення
Усі номери нижче — запропонований план нової ітерації, не стан старої VIRA.
Таблиця описує початкову послідовність етапів. Поточний обсяг наведено в [довідці застосунку](../app/README.md).

| Версія | Обсяг | Критерій виходу |
|---|---|---|
| app v0.1.0 | Перевірений StarterSample, greybox однієї кімнати, фіксований екран із логотипом, summon/recenter UI | Запуск на Quest; UI можна викликати/сховати; tracking loss не натискає кнопки |
| app v0.2.0 | Featured Discover, grid search, loading/empty/error, постери | Демодані явно позначені; живий каталог окремо перевірений; stale search не перезаписує нові результати |
| app v0.3.0 | Розкладна картка, Library, local drop, Room CRUD | Весь сценарій add/status/progress/delete переживає перезапуск; unfold не руйнує touch/grab |
| app v0.4.0 | Дозволений video demo, episode selection, side docking, rating/status | Відео й UI узгоджені; позиція зберігається; recall картки не перезапускає відео |
| app v0.5.0 | Акаунт, синхронізація, профіль, початкові представлення | Ізоляція даних, logout, offline/reconnect та конфлікти перевірені |
| app v0.6.0 | Приватний co-watch, провайдерні експерименти | Два пристрої; виміряний sync/reconnect; кожен провайдер має окремий capability report |

Соціальні можливості, голос, публічні кімнати, довільні аватари й персоналізація не видаляються з бачення,
але не можуть затримувати перевірку першої кімнати.
Не відкривати десяток порожніх «готових» вкладок: непідтверджені функції мають бути явно unavailable/prototype.

## Перший наскрізний результат
Room → summon → Discover → unfold card → Library → restart → збережений запис.
Video prototype може йти окремим технічним spike після перевірки бази; він не підтверджує Netflix/Crunchyroll.

## Вихід із кожного етапу
Scope виконаний; тести збережені з командами й результатами; Quest-перевірки позначені окремо;
відомі помилки записані; користувацькі дані не втрачені; diff переглянуто; handoff оновлено.
