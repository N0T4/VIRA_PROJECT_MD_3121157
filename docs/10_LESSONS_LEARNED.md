# Уроки попередньої версії

| Що було / ризик | Що робимо тепер |
|---|---|
| Розробка змішувалася з розширенням scope | Одна задача, scope gate, явні excluded items |
| Legacy flat card не відповідає новій вимозі | Новий foldable object; не плутати rotate з unfold |
| Poke/grab поверхні конфліктували | Окремі hit areas, ownership, regression on device |
| Підготовлені instrumentation tests можна помилково назвати пройденими | Статуси build/execute/device окремо |
| Live API повертав 403 у середовищі розробки | Явний demo/offline; причину не вигадувати; повторна перевірка на Quest |
| Старі кольори hover/held не збігаються з новим дизайном | Нові semantic tokens; старі значення — тільки history |
| Невідомі інтеграції відео намальовані як готові | Capability matrix та UNKNOWN замість фальшивого підключення |

Не повторювати старий проект автоматично. Не видаляти корисні бізнес-правила (duplicate guard,
збереження прогресу, розділення даних і просторової взаємодії) лише через нову візуальну ітерацію.
