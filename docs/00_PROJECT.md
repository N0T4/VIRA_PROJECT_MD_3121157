# VIRA — загальний опис
Поточна реалізація містить кімнату, локальний каталог, Anime Card, Library та демовідтворення.

## Продукт
Персональний VR-простір на Meta Quest 3 для пошуку аніме, ведення колекції,
перегляду та майбутнього спільного досвіду. Android/Kotlin + Meta Spatial SDK — технологічний напрям.
VIRA — одне місце, а не набір різних кімнат для кожної дії.

## Основний досвід
1. Вхід у кімнату; на нерухомому головному екрані логотип VIRA.
2. Жест викликає інструменти перед користувачем.
3. Пошук у Discover або вибір із Library.
4. Натискання на тайтл створює рухому просторову картку.
5. Картка розгортається для деталей і вибору епізоду.
6. Тайтл можна додати через локальну drop-зону або дію UI.
7. Під час відео картка прихована збоку, але повертається за викликом.
8. Із неї можна змінити епізод, поставити оцінку або змінити статус.

## Повний обсяг
Discover, пошук/фільтри, Library зі статусами й прогресом, unfolded Anime Card,
основний екран, керування переглядом, акаунти/синхронізація, Social/co-op,
персоналізація, аватари та маскот. Наявність у плані не означає наявності у v0.1.

## Принципи
- Стиль фіксують рольові референси, поведінку — текстові рішення користувача.
- User data окремі від catalog data й тимчасових spatial state.
- Локальні дії не залежать від готовності всіх майбутніх відеопровайдерів.
- Assets replaceable: оновлені ресурси можуть замінити тимчасові моделі/анімації без зміни бізнес-логіки.
- Розробка по вертикальних сценаріях, з перевіркою в Quest.
