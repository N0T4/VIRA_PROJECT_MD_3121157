# Версії

Код застосунку редагується в `app/`. Коміти Git зберігають історію вихідних файлів. Для кожної перевіреної версії записують commit, перелік змін і результати збірки та тестів на Quest.

Мітка версії позначає конкретний commit. APK збирається з цієї ревізії через Gradle wrapper. Для перевірки старої версії відкрийте її в окремій робочій папці, щоб зберегти поточні зміни.
